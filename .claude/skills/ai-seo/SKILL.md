# AI SEO (GEO / AEO)

## Principles
AI answers cite pages that are crawlable, clear, specific and trustworthy. Classic SEO is the foundation; this adds extractability.

## Checklist
1. **Access**: robots.txt does not block AI crawlers you want (for example GPTBot, ClaudeBot, PerplexityBot, Google-Extended). Decide deliberately and tell the user the trade-off.
2. **Answer first**: put a direct 1 to 3 sentence answer under each question-style heading, then detail.
3. **Structure**: descriptive H2/H3 phrased as real questions, short paragraphs, lists and tables for comparisons and steps.
4. **Specifics**: original data, numbers, dates, named sources and examples. Vague text rarely gets cited.
5. **Entity clarity**: consistent brand name, who/what/where, author bios, about page, and links to official profiles.
6. **Schema**: FAQPage, HowTo, Article, Organization, Product where accurate.
7. **Freshness**: visible updated dates, and keep key facts current.
8. **Off-site presence**: reviews, directories, Wikipedia/Wikidata if eligible, forums and communities where the audience asks questions.
9. **Optional**: an `llms.txt` file summarizing key pages (support among AI products varies; treat it as low-cost, not proven).

## Measure
Run a set of 10 to 20 target questions in several AI tools monthly and record whether the brand is mentioned or cited and which pages are used. Report as observations, since results vary by run.

## Output
Page-by-page recommendations with rewritten headings and answer blocks the user can paste.
