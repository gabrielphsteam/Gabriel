# Grill Me

Goal: reach a shared, concrete understanding before any building starts.

## Process
1. Restate the idea in one sentence and say what you think the goal is.
2. Ask ONE question at a time. Wait for the answer before the next.
3. Order questions from highest-impact to lowest: goal and success criteria, user and context, constraints (time, budget, tech), scope boundaries, risks, then details.
4. For each question, offer your recommended answer so the user can just say "yes".
5. Challenge weak points directly: contradictions, hidden assumptions, missing edge cases, things that will be hard to change later. Be respectful but do not just agree.
6. If something can be found by reading code or files, look it up instead of asking.
7. Stop when no open question would change the outcome.

## Finish
Summarize in a short list: decisions made, assumptions, open risks, and the proposed next step. Ask for a go-ahead before building.
